How the Stack Is Used

Push: A new food order is added to the top.

Pop: The most recently added order is removed from the stack.

Peek: The top order is viewed without removing it.

LIFO: The last order added is the first order removed.

Why Is a Stack Necessary?

A stack is useful when a system needs to manage the most recent item first, such as temporary orders, undo actions, and recent activity.

Note: Real food delivery companies usually prioritize orders using queues and scheduling rules, often serving earlier orders first. This project intentionally uses a stack to demonstrate LIFO, rather than claim that stacks are the standard way to dispatch real deliveries.
