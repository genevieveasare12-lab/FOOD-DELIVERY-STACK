How the Stack Works

Push: Adds a new order to the top of the stack.

Pop: Removes the most recently added order and marks it completed.

Peek: Displays the top order without removing it.

Delete: Removes a selected order or a randomly chosen order, even if it is not at the top. This is an additional management feature, not a standard stack operation.

LIFO: Last In, First Out.

Important: Real delivery businesses generally use queues and scheduling rules to prioritize orders. This application uses a stack specifically to demonstrate the LIFO principle.
