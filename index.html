FOOD ORDER MANAGEMENT SYSTEM

A data structures project demonstrating stack operations in food order management.

❓ Why Is a Stack Necessary?

A stack stores orders in Last In, First Out (LIFO) order. The most recently added order is at the top.

  1. push(): Adds a new order to the top of the stack.
  2. pop(): Removes the order at the top when it is processed or cancelled.
  3. top(): Shows the latest order without removing it.
  4. empty(): Checks whether there are any orders in the stack before trying to remove one.
  5. Order tracking: Makes it easy to identify the most recently added order.
  6. Underflow prevention: Checking empty() prevents trying to pop an order when none exists.
Example: Add Order A, then Order B. Order B is now on top. Calling pop() removes Order B first, because it was added last.

Academic note: Real delivery dispatch systems commonly use queues so the oldest order can be served first. This application deliberately uses a stack to demonstrate LIFO operations for a data structures assignment; it is not claiming that LIFO is the normal way to dispatch food deliveries.
